Write a handover for whoever continues this work, including a future
session with no access to this conversation.

Review the conversation from the beginning. Do not rely on a general
recollection; seemingly minor details may be essential.

Include the following sections where relevant, omitting any empty headings:

- **Context** — explain the purpose of the work in one or two sentences.
- **Still open** — identify unfinished work, unanswered questions, and
  external dependencies.
- **Decisions** — record settled choices that must not be reopened, with a
  brief reason for each. Without that reason, a later reader may reverse a
  decision without understanding its basis.
- **Where things are** — provide files, folders, and addresses, using full paths.
- **What went wrong** — describe unsuccessful approaches and lessons learned
  so the next session does not repeat them.
- **Rejected** — list proposals that were declined so they are not suggested again.

Use the conversation's language. Prefer measured values and exact paths
to vague descriptions.

Save the handover as a file and state its location.

The user's instructions in the same message take precedence. If they
request "two sentences", write two sentences without asking which
instruction to follow.
