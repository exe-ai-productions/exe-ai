Kapitel 01 / 16

Erste Schritte

Vom ersten Start bis zur ersten Antwort.

Beim ersten Start begrüßt dich das Fenster Willkommen. Es fragt nach drei Dingen: deiner Anrede, der Sprache und dem Erscheinungsbild. All das kannst du später in den Einstellungen ändern. Ein Konto brauchst du nicht.

Drei Schritte zum ersten Modell

Schritt 1

Server-Programm downloaden

Öffne unten in der linken Leiste Lokal. Über die Download-Schaltfläche lädst du den Modell-Server herunter. Dieses kleine, freie Programm übernimmt die Berechnungen.

Schritt 2

Modell wählen

Öffne den Katalog. Er zeigt Modelle, die zum Speicher deines Rechners passen. Mit Herunterladen lädst du das gewählte Modell herunter.

Schritt 3

Starten

Zurück unter Lokal drückst du Start. Die Felder für Kontext, GPU-Layer und Port sind bereits ausgefüllt. Wird der Punkt grün, läuft der Server, und dein Modell steht im Chat zur Wahl.

Lieber ein Modell aus der Cloud? Öffne Cloud, wähle Anbieter hinzufügen, füge deinen Schlüssel ein und drücke Verbinden. Die Modelle des Anbieters erscheinen automatisch.

Sie zeigt, was der Assistent neben dem Chat erstellt und ausführt. Auch hier findest du unten sechs Symbole:

Die Statuszeile zeigt, ob der Modell-Server läuft – Server aktiv oder Server inaktiv – und wie viel Arbeitsspeicher belegt ist.

Kapitel 03 / 16

Chats und Projekte

Jedes Gespräch ist ein Chat. Projekte halten zusammen, was zusammengehört.

Mit Neuer Chat startest du ein leeres Gespräch. Über Chats durchsuchen findest du bestehende Gespräche wieder. Ein Rechtsklick auf einen Chat – oder ein Klick auf die Schaltfläche Mehr in seiner Zeile – öffnet sein Menü:

AnheftenDer Chat bleibt oben stehen, unter „Angeheftet“.
UmbenennenGibt dem Chat einen neuen Titel.
In ProjektVerschiebt den Chat in ein Projekt.
ArchivierenDer Chat verschwindet aus der Liste, bleibt aber erhalten. Im Archiv kannst du ihn mit Zurückholen wiederherstellen.
LöschenEntfernt den Chat. Arbeitet darin noch ein Agent, wird auch dieser gestoppt.

Projekte

Ein Projekt ist eine Gruppe von Chats mit eigenem Namen. Die Chats eines Projekts teilen sich ihre Arbeitsordner. Neues Projekt legt eines an. Auch ein ganzes Projekt lässt sich archivieren.

Der Statuspunkt neben einem Chat

GelbWartet auf dich
BlauAntwort läuft
GrünAntwort fertig
RotLauf fehlgeschlagen

Die Warteschlange

Schreibst du, während eine Antwort erstellt wird, erhält deine Nachricht den Status In der Warteschlange. Sie wird gesendet, sobald die Antwort fertig ist. Mit Aus der Schlange nehmen übernimmst du sie wieder ins Eingabefeld.

Kapitel 05 / 16

Antworten lesen

Eine Antwort zeigt nicht nur den Text, sondern auch, wie sie entstanden ist.

Denken

Denkt das Modell nach, steht über der Antwort eine eingeklappte Zeile mit der Beschriftung Denken. Ein Klick klappt sie auf.

Werkzeuge

Jeder Werkzeugaufruf erscheint als kleine Kachel mit Namen und Dauer. Schlägt der Aufruf fehl, steht „fehlgeschlagen“ auf der Kachel. Ein Klick zeigt, was genau ausgeführt wurde.

Unter der Antwort

Kopieren legt den Text in die Zwischenablage. Neu erzeugen lässt das Modell noch einmal antworten. Daneben stehen Messwerte: TPS zeigt, wie schnell das Modell schreibt; TTFT zeigt, wie lange es bis zur ersten Textausgabe gedauert hat.

Rückfragen

Manchmal stellt der Assistent eine Rückfrage. Du wählst eine der Antworten oder schreibst eine eigene. Mit Später antworten verschiebst du die Beantwortung.

Wenn der Kontext voll wird

Ist der Kontext fast voll, fasst der Chat seine älteren Teile zusammen. An der Stelle steht dann zum Beispiel „12 komprimierte Nachrichten“. Nichts geht verloren: Der Verlauf bleibt lesbar, das Modell bekommt die Zusammenfassung. Ab welchem Füllstand das passiert, stellst du unter Einstellungen → Anweisungen → Kontext-Komprimierung ein. „Auto“ heißt 80 %. Diese Funktion ist noch in der Entwicklung.

Kapitel 06 / 16

Modelle

Lokal heißt: Nichts, was du tippst, verlässt deinen Rechner. Cloud heißt: Dein Text wird an einen Anbieter übertragen, der die Nutzung abrechnet.

Der Katalog

Der Katalog hat sechs Reiter: Chat, Einbettung, Sprache, Bild, Zubehör und Downloads. Jede Karte zeigt, was ein Modell kann: „Ruft Werkzeuge“, „Sieht Bilder“, „Denkt vor der Antwort“, „Hat ein Tempo-Modul“. Ein Hinweis wie „Empfohlen für deine 64 GB“ zeigt, ob es zu deinem Rechner passt. Über das Suchfeld findest du außerdem Modelle direkt bei Hugging Face. Unter Downloads siehst du, was gerade heruntergeladen wird.

Lokal: sechs Server

Unter Lokal hat jeder Server seine eigene Kachel.

Modell-ServerDas Modell, mit dem du chattest.
Agenten-ServerDas Modell, auf dem Agenten und Cronjobs laufen.
Einbettungs-ServerBereitet Dokumente für die Suche vor. Er wird auf Anfrage geladen.
Sprach-ServerDiktat, Gespräch und Stimme.
Bereinigungs-ServerEin kleines Modell, das diktierten Text glättet.
Bild-ServerHält das Bildmodell geladen, damit das Zeichnen nicht jedes Mal von vorn beginnt.

Auf der Seite eines Servers wählst du das Modell und stellst es ein: Kontext (wie viel das Modell auf einmal im Blick hat), GPU-Layer (wie viel davon die Grafikkarte berechnet), CPU-Threads, dazu Tempo-Modul und Vision-Modul. Unter Erweitert findest du Einstellungen wie KV-Cache, Flash Attention und Memory Lock. Das Server-Log zeigt, was der Server meldet. Mit Start und Stopp startest und stoppst du ihn.

Unter Parameter stehen Werte wie die Temperatur. Sie gelten für alle Chats mit diesem Modell. Zurücksetzen stellt die Vorgaben wieder her.

Cloud

Anbieter hinzufügen verbindet Anthropic, OpenAI oder einen eigenen Server, der die OpenAI-Schnittstelle unterstützt – zum Beispiel oMLX oder LM Studio. Dein Schlüssel bleibt auf diesem Rechner, in einer Datei, die nur das Programm liest. Danach wird nur noch angezeigt, ob einer gesetzt ist.

Cloud-Anbieter melden oft nicht, was ein Modell kann. Auf der Seite des Modells aktivierst du deshalb selbst die passenden Optionen: Modell kann Bilder sehen (Vision), Modell kann denken (Reasoning), Modell kann Werkzeuge benutzen (Tool Calls).

Kapitel 07 / 16

Ordner und Dokumente

In einem freigegebenen Ordner arbeitet das Modell ohne Rückfrage. Bei Zugriffen außerhalb dieses Ordners fragt es im Chat nach.

Arbeitsordner

Über Arbeitsordner gibst du einen Ordner frei: Ordner suchen oder Pfad einfügen, dann Freigeben. Weiteren Ordner freigeben fügt einen weiteren hinzu. Ordner nicht mehr freigeben nimmt die Freigabe zurück; gelöscht wird dabei nichts.

Jeder Chat hat außerdem einen eigenen Ordner. Chats in einem Projekt teilen sich die Ordner des Projekts.

Die Notizen im Ordner

In jedem freigegebenen Ordner liegt eine Datei exe.md. Darin stehen Notizen zu diesem Ordner. Sie werden mit jeder Nachricht übermittelt, und der Assistent hält sie aktuell.

Dokumente anhängen

Dateien hochladen akzeptiert Bilder – für Modelle, die sehen können – sowie Dokumente bis 20 MB: PDFs und Textdateien wie TXT, MD, CSV, JSON oder Quelltextdateien.

Ein Dokument wird vollständig in den Kontext aufgenommen; auf seiner Karte steht dann „Vollständig im Kontext“. Passt es nicht vollständig hinein, steht dort „Dokument zu groß“. Die Datei bleibt trotzdem im Ordner des Chats, und der Assistent liest einzelne Stellen daraus.

Der Doc-Ordner

Der Doc-Ordner in der rechten Leiste sammelt alles, was du hochgeladen hast und was Agenten und Cronjobs abgelegt haben. Bei jeder Datei wird angezeigt, von wem sie stammt. Die Ansicht Alle Projekte zeigt die Dateien aller Projekte.

Zieh eine Datei in den Chat, um sie anzuhängen. Mit Dateien hinzufügen fügst du weitere Dateien hinzu. Über Speicherort ändern verschiebst du den Ordner.

Kapitel 08 / 16

Werkzeuge und Freigaben

Mit Werkzeugen kann der Assistent mehr als schreiben: Dateien lesen, Befehle ausführen, im Netz suchen, Bilder zeichnen. Du bestimmst, was er darf.

Der Berechtigungsmodus

Auto

Werkzeuge laufen ohne Rückfrage – auch außerhalb der Arbeitsordner.

Manuell

In den Arbeitsordnern arbeiten Datei- und Befehlswerkzeuge ohne Rückfrage. Außerhalb davon und bei anderen Werkzeugen wird in der Regel erst gefragt.

Eingeschränkt

Auch in den Arbeitsordnern wird vor jedem Datei- und Befehlszugriff gefragt.

Nach einer Neuinstallation ist der Modus „Manuell“ eingestellt. Solange du selbst noch keinen Modus gewählt hast, fragt das Programm nur bei Datei- und Befehlszugriffen außerhalb der Arbeitsordner. Bei Agenten heißt die mittlere Stufe „Sandboxed“.

Die Frage „Ausführen erlauben?“

Braucht ein Werkzeug deine Zustimmung, zeigt die Abfrage genau, was ausgeführt werden soll und warum deine Zustimmung erforderlich ist – etwa weil ein Pfad außerhalb der freigegebenen Ordner liegt oder der Zugriff ins Netz geht.

Dieses Mal erlaubenGilt nur für diesen einen Aufruf.
Immer erlaubenGilt ab jetzt für das ganze Werkzeug, in allen Chats und allen Agentenläufen.
NeinLehnt ab. Du kannst dazuschreiben, was der Assistent stattdessen tun soll.

Eine mit „Immer erlauben“ erteilte Freigabe widerrufst du in der Datei berechtigungen.json im Datenordner des Programms (siehe Deine Daten). Einige gefährliche Befehle bleiben in jedem Modus gesperrt.

Agenten, die unbeaufsichtigt laufen, lehnen alles ab, was eine Zustimmung bräuchte. Agenten, die du aus einem Chat startest, schicken die Frage in diesen Chat.

Unter Einstellungen → Werkzeuge hat jedes Werkzeug einen Schalter. Jedes aktive Werkzeug kostet bei jeder Anfrage etwas Zeit – schalte aus, was du nicht brauchst.

Unter Einstellungen → MCP-Server verbindest du Exe AI mit Anwendungen, die du täglich nutzt – zum Beispiel Notion, GitHub, Figma, Gmail, Recraft, Hugging Face, Google Drive oder Slack. Je nach Dienst meldest du dich im Browser an oder trägst einen API-Schlüssel ein. Unter Eigener Server kannst du eine Adresse oder einen Startbefehl eintragen. Die Websuche ist schon eingebaut.

Was ein Werkzeug zurückgibt, behandelt das Programm als Daten, nicht als Anweisung. Das gilt auch für Text von Webseiten.

Kapitel 09 / 16

Agenten und Cronjobs

Ein Agent erledigt eine Aufgabe selbstständig und erstellt einen Bericht. Ein Cronjob führt eine Aufgabe zu einer festgelegten Zeit aus.

Einen Agenten anlegen

Einstellungen → Agenten. Ein Agent hat einen Namen, eine Beschreibung, eine Anweisung, seine Werkzeuge, seine Ordner und Grenzen: Max. Runden, Max. Minuten, Max. Token. Jeder Agent ist eine einzelne Markdown-Datei.

Eine Aufgabe starten

Rechte Leiste → Agenten → Neue Aufgabe: Agent wählen, Aufgabe beschreiben, Starten. Du kannst den Assistenten auch im Chat bitten, einen Agenten zu starten.

Verfolgen

Unter Aktive Aufgaben siehst du, was läuft. Unter Berichte findest du die Ergebnisse. Ein Lauf hat einen der folgenden Status: „läuft“, „wartet auf dich“, „fertig“, „abgebrochen“, „fehlgeschlagen“ oder „unterbrochen“. Stellt ein Agent eine Rückfrage, wartet er auf deine Antwort.

Modell und Subagenten

Auf welchem Modell Agenten laufen, bestimmt Modell für Agenten & Cronjobs auf der Seite des Agenten-Servers unter Lokal.

Der Assistent kann eine Teilaufgabe auch an einen Subagenten geben, ohne dass du vorher einen Agenten anlegst. Die Grenzen dafür stehen auf der Seite Agenten unter Subagenten.

Cronjobs

Rechte Leiste → Cronjobs zeigt einen Kalender mit Tag und Monat. Neuer Cronjob fragt drei Angaben ab:

ArtAgent, Skript oder Erinnerung
WiederholungEinmal, Täglich, Wöchentlich, Monatlich oder Eigene (mit einem Cron-Ausdruck)
Uhrzeitwann es losgeht

Du kannst es dem Assistenten auch einfach sagen, zum Beispiel: „Erinnere mich jeden Morgen um acht an die Post.“

Jetzt starten lässt einen Cronjob sofort laufen. Unter Letzte Läufe siehst du die Ergebnisse. Hat ein Cronjob ein Ziel, meldet sich nur der Lauf, der es erreicht. Scheitert ein Cronjob mehrmals hintereinander, wird er pausiert, bis du ihn wieder aktivierst.

Kapitel 10 / 16

Bilder und Video

Das Symbol „Bilder“ unten in der linken Leiste öffnet den Bereich, in dem du Bilder und Videos erzeugst. Die Bild- und Videogenerierung läuft auf deinem Rechner.

Was du brauchst

Du benötigst ein Bildmodell aus dem Reiter Bild im Katalog. Die Software zur Bildgenerierung lädst du unter Lokal → Bild-Server über Framework herunterladen einmalig herunter.

So geht es

Schreib in die Prompt-Leiste, was gezeichnet werden soll. Verbessern formuliert deinen Prompt auf Englisch und ergänzt Details. Rückgängig stellt deinen ursprünglichen Text wieder her. Zeichnen startet die Generierung, Stopp bricht sie ab.

Stil, LoRA, EmbeddingsZusätze, die den Stil eines Bildes lenken.

Fertige Bilder liegen in der Galerie in der rechten Leiste. Auch der Assistent kann im Chat Bilder generieren, wenn du ihn darum bittest. Der Schalter Bild-Metadaten entfernen unter Einstellungen → Gedächtnis entfernt Prompt, Einstellungen und EXIF-Daten aus jedem Bild.

Kapitel 11 / 16

Diktat und Gespräch

Für beides benötigst du den Sprach-Server unter „Lokal“ und ein Sprachmodell aus dem Reiter „Sprache“ im Katalog. Spracherkennung und Sprachausgabe laufen auf deinem Rechner.

Diktat

Ein Klick auf das Mikrofon startet das Diktat, ein zweiter beendet es. Schon beim Sprechen siehst du einen vorläufigen Text.

Auf Wunsch glättet ein Modell den Text. Welches Modell das übernimmt, wählst du auf der Seite des Sprach-Servers unter Bereinigt durch. Mit Diktat Automatik wird der Text am Ende automatisch gesendet; andernfalls sendest du ihn selbst.

Gespräch

Halte die Mikrofon-Schaltfläche eine Sekunde gedrückt. Das Programm hört zu, denkt nach und spricht. Mit Antworten vorlesen und einer gewählten Stimme hörst du jede Antwort. Die Stimme kommt von einem eigenen Modell aus dem Katalog.

Bleibt drei Runden lang eine Antwort von dir aus, endet das Gespräch von selbst.

Die Tastenkombinationen ⌘ ⇧ M und Strg + Umschalt + M funktionieren überall: Sie bringen das Fenster in den Vordergrund und lösen dieselbe Aktion aus wie ein Klick auf das Mikrofon – auch wenn gerade ein anderes Programm im Vordergrund ist.

Kapitel 12 / 16

Was der Assistent weiß

Vier Dinge begleiten jedes Gespräch. Jedes davon kannst du lesen, ändern und abschalten.

Anweisungen

Einstellungen → Anweisungen. Hier schreibst du, wie sich der Assistent verhalten soll. Anweisungen für diesen Chat aussetzen schaltet sie für den offenen Chat ab.

Gedächtnis

Einstellungen → Gedächtnis. Regeln und Fakten, die über mehrere Gespräche hinweg gelten. Der Assistent fügt selbst Einträge hinzu; du kannst sie lesen, ändern oder mit Leeren vollständig entfernen.

An lokale Modelle schicken – die Einträge bleiben auf diesem Rechner. An Cloud-Modelle schicken – die Einträge werden bei jeder Anfrage an den Anbieter übertragen.

Dein Name

Er steht unter Anrede auf der Seite Anweisungen. Der Schalter Begrüßung & Anrede zeigt den Gruß und gibt den Modellen deinen Namen mit. Ist der Schalter deaktiviert, entfallen beide Funktionen. Bei Cloud-Modellen wird der Name an den Anbieter übertragen.

Skills

Ein Skill ist eine schriftlich festgehaltene Arbeitsweise. Du rufst ihn mit seinem Namen hinter einem Schrägstrich auf. Mitgeliefert sind /cleanup, /cronjob, /grill-me, /handoff, /hilfe und /image-generator.

Einstellungen → Skills: Skills von selbst anbieten lässt das Modell einen Skill wählen, ohne dass du ihn nennst. Skill schreiben legt einen eigenen an. Zurücksetzen stellt einen geänderten mitgelieferten Skill wieder her.

Dazu kommen die Notizen in der Datei exe.md in jedem freigegebenen Ordner (siehe Ordner und Dokumente).

Drei Grenzen auf der Seite Anweisungen

WerkzeugrundenWie oft das Modell innerhalb einer Antwort Werkzeuge aufrufen darf. Aufgaben mit vielen Dateien benötigen mehr Aufrufe. Auto heißt 50.
Befehls-ZeitgrenzeWie lange ein Shell-Befehl laufen darf, in Sekunden. Downloads und Builds benötigen mehr Zeit. Auto heißt 120.
Kontext-KomprimierungAb welchem Füllstand ein Chat sich selbst zusammenfasst, in Prozent. 1 bis 85; Auto heißt 80.

Kapitel 15 / 16

Deine Daten

Exe AI ist so aufgebaut, dass deine Daten bei dir bleiben.

  • Das Programm ist nur von deinem eigenen Rechner aus erreichbar (Adresse 127.0.0.1). Chats, Einstellungen, Schlüssel und Modelle liegen lokal, in Dateien und einer Datenbank.
  • Mit einem lokalen Modell verlässt nichts, was du tippst, deinen Rechner. Mit einem Cloud-Modell wird dein Text an den Anbieter übertragen.
  • API-Schlüssel liegen in einer lokalen Datei mit eingeschränkten Rechten und werden nie wieder angezeigt. Die Oberfläche erfährt nur, ob ein Schlüssel gesetzt ist.
  • Die Einträge aus deinem Gedächtnis werden nur dann an Cloud-Anbieter übertragen, wenn du diese Option aktivierst. Dein Name wird mit jedem Gespräch übermittelt, auch an Cloud-Anbieter, solange „Begrüßung & Anrede“ aktiviert ist.
  • Modelle werden direkt von huggingface.co heruntergeladen.
