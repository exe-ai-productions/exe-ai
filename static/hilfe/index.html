Chapter 01 / 17

Getting started

From the first launch to your first response.

When you first launch the app, you see the Welcome window. It asks for three things: your preferred name, language, and appearance. You can change all of these later in Settings. You do not need an account.

Three steps to your first model

Step 1

Download the server software

Open Local at the bottom of the left sidebar. Use the download button to download the model server, a small, free program that performs the calculations.

Step 2

Choose a model

Open the Catalog to see models that fit your computer's memory. Select a model and choose Download.

Step 3

Start

Go back to Local and press Start. Context, GPU layers, and port are already filled in. When the indicator turns green, the server is running and your model is available in the chat.

Prefer a cloud model? Open Cloud, select Add provider, enter your key, and press Connect. The provider's models appear automatically.

Chapter 03 / 17

Chats and projects

Each conversation is a chat. Projects group related chats.

New chat starts an empty conversation. Search chats helps you find an existing one. Right-click a chat, or click the More button in its row, to open its menu:

PinKeeps the chat at the top, under “Pinned.”
RenameGives the chat a new title.
Move to projectMoves the chat into a project.
ArchiveRemoves the chat from the list without deleting it. In the Archive, use Restore to bring it back.
DeleteDeletes the chat. If an agent is still working in it, the agent is stopped as well.

Projects

A project is a named group of chats. Chats in the same project share their working folders. New project creates a project. You can also archive an entire project.

Chapter 05 / 17

Reading responses

A response shows both the text and how it was produced.

Thinking

If the model uses reasoning, a collapsed row labeled Thinking appears above the response. Click to expand it.

Tools

Each tool call appears as a small card showing its name and duration. If the call fails, the card is marked “Failed.” Click to see exactly what ran.

Below the response

Copy places the text on the clipboard. Regenerate asks the model to respond again. The adjacent performance metrics show generation speed (TPS) and the time until the first text output (TTFT).

Follow-up questions

The assistant may ask a follow-up question. Choose an answer or write your own. Answer later lets you postpone your response.

When the context fills up

When the context is almost full, the chat summarizes its older messages. A label such as “12 compressed messages” appears in their place. Nothing is lost: the history remains readable, while the model receives the summary. Set the threshold under Settings → Instructions → Context compression. “Auto” means 80%. This feature is still in development.

Chapter 06 / 17

Models

Local means that nothing you type leaves your computer. Cloud means that your text is sent to a provider, which bills you for usage.

The catalog

The catalog has six tabs: Chat, Embedding, Speech, Image, Accessories, and Downloads. Each card shows a model's capabilities: “Calls tools,” “Sees images,” “Thinks before responding,” and “Has a speed module.” A line such as “Recommended for your 64 GB” tells you whether it fits your computer. You can also use the search field to find models directly on Hugging Face. Under Downloads, you can see what is currently downloading.

Local: six servers

Under Local, each server has its own card.

Model serverThe model you chat with.
Agent serverThe model used by agents and cron jobs.
Embedding serverPrepares documents for search. It is loaded on demand.
Speech serverDictation, conversation, and voice.
Cleanup serverA small model that polishes dictated text.
Image serverKeeps the image model loaded so it does not need to be reloaded for each image.

On a server's page, choose a model and configure it: Context (how much the model can consider at once), GPU layers (how much of the processing the graphics card handles), CPU threads, plus the Speed module and Vision module. Under Advanced, you will find settings such as KV cache, Flash Attention, and Memory Lock. The Server log shows the server's messages. Use Start and Stop to start and stop it.

Under Parameters, you will find values such as temperature. They apply to all chats using this model. Reset restores the defaults.

Cloud

Add provider connects Anthropic, OpenAI, or a custom server that supports the OpenAI API, such as oMLX or LM Studio. Your key stays on this computer, in a file read only by the app. After that, the interface only shows whether a key has been set.

Cloud providers often do not report a model's capabilities. Enable the appropriate options yourself on the model's page: Model can see images (Vision), Model can think (Reasoning), Model can use tools (Tool Calls).

Chapter 07 / 17

Folders and documents

In an approved folder, the model works without asking. For access outside that folder, it asks in the chat.

Working folders

Use Working folders to grant access to a folder: browse for a folder or paste its path, then select Grant access. Grant access to another folder adds another one. Revoke folder access removes permission without deleting anything.

Each chat also has its own folder. Chats in a project share the project's folders.

Folder notes

Each approved folder contains a file named exe.md with notes about that folder. These notes accompany every message, and the assistant keeps them up to date.

Attaching documents

Use Upload files to attach images, for models that can see them, and documents up to 20 MB: PDFs and text files such as TXT, MD, CSV, JSON, or source code files.

A document is included in full in the context; its card then says “Fully in context.” If it does not fit, the card says “Document too large.” The file still remains in the chat's folder, and the assistant reads individual passages from it.

The Doc folder

The Doc folder in the right sidebar collects everything you have uploaded and everything agents and cron jobs have saved. Each file shows who created or uploaded it. The All projects view shows files from every project.

Drag a file into the chat to attach it. Add files adds new files; Change location moves the folder.

Chapter 08 / 17

Tools and permissions

Tools let the assistant do more than write: read files, run commands, search the web, and generate images. You decide what it is allowed to do.

Permission mode

Auto

Tools run without asking, even outside working folders.

Manual

File and command tools work without asking inside working folders. Outside those folders, and for other tools, permission is generally requested first.

Restricted

Permission is requested before every file operation and command, even inside working folders.

After a fresh installation, the mode is set to Manual. Until you choose a mode yourself, the app asks only about file operations and commands outside working folders. For agents, the middle level is called “Sandboxed.”

The “Allow execution?” prompt

When a tool needs your permission, the prompt shows exactly what will run and why approval is needed, for example because a path is outside the approved folders or the operation accesses the network.

Allow onceApplies only to this particular call.
Always allowFrom now on, applies to the entire tool in all chats and all agent runs.
NoDenies permission. You can add a note explaining what the assistant should do instead.

To revoke an “Always allow” permission, edit berechtigungen.json in the app's data folder (see Your data). Some dangerous commands remain blocked in every mode.

Unattended agents reject anything that would need approval. Agents you start from a chat send their approval requests to that chat.

Chapter 09 / 17

Agents and cron jobs

An agent completes a task independently and returns a report. A cron job runs a task at a scheduled time.

Creating an agent

Settings → Agents. An agent has a name, description, instructions, tools, folders, and limits: Max. rounds, Max. minutes, Max. tokens. Each agent is stored as a single Markdown file.

Starting a task

Right sidebar → Agents → New task: choose an agent, describe the task, and select Start. You can also ask the assistant in the chat to start an agent.

Tracking progress

The Active tasks section shows what is running. The Reports section collects the results. A run has one of these statuses: “Running,” “Waiting for you,” “Complete,” “Canceled,” “Failed,” or “Interrupted.” If an agent asks a question, it waits for your answer.

Model and subagents

The model used by agents is selected through Model for agents & cron jobs on the agent server's page under Local.

The assistant can also delegate a subtask to a subagent without you creating an agent first. The limits are on the Agents page under Subagents.

Cron jobs

Right sidebar → Cron jobs opens a calendar with Day and Month views. New cron job asks for three details:

TypeAgent, Script, or Reminder
RepeatOnce, Daily, Weekly, Monthly, or Custom (using a cron expression)
Timewhen to start

You can also simply tell the assistant, for example: “Remind me to check the mail every morning at eight.”

Run now starts a cron job immediately. Recent runs shows the results. If a cron job has a goal, only a run that reaches it sends a notification. After several consecutive failures, the cron job is paused until you enable it again.

Chapter 10 / 17

Images and video

The Images icon at the bottom of the left sidebar opens the area where you generate images and videos. Generation runs on your computer.

What you need

You need an image model from the catalog's Image tab. Download the image generation software once under Local → Image server using Download framework.

How it works

Describe the image in the prompt bar. Enhance rewrites your prompt in English and adds details. Undo restores your original text. Generate starts image generation; Stop cancels it.

SettingPurpose
Model, formatWhich model is used and the image's aspect ratio.
Dimensions & generationWidth, height, steps, CFG, and seed.
Style, LoRA, embeddingsAdd-ons that guide the image's style.
Input imageAn existing image to edit.
MaskUse the brush to mark the areas to regenerate.
Reference imagesImages that guide the model during editing. Some models accept multiple reference images.
FaceADetailer finds faces in the finished image and sharpens them.
Face transferPuLID transfers a face from a photo.
Pose & structureControlNet guides the pose or outlines.
UpscalingHires fix generates a larger version of the image in a second pass.

Switch between Image and Video. Video has four modes: “Text to video,” “Image to video,” “First and last frame,” and “Video to video.” Video is still experimental. The available options depend on the selected model.

Finished images appear in the Gallery in the right sidebar. The assistant can also generate images in the chat when you ask. The Remove image metadata switch under Settings → Memory removes the prompt, settings, and EXIF data from each image.

Chapter 11 / 17

Dictation and conversation

Both require the speech server under Local and a speech model from the catalog's Speech tab. Speech recognition and speech generation run on your computer.

Dictation

Click the microphone to start dictation; click again to stop. A preliminary transcript appears as you speak.

Optionally, a model can polish the text. Select the model on the speech server's page under Cleaned up by. With Automatic dictation, the text is sent automatically when you finish; otherwise, you send it yourself.

Conversation

Hold the microphone button for one second. The app listens, thinks, and speaks. Enable Read responses aloud and choose a Voice to hear every response. The voice uses a separate model from the catalog.

The conversation ends automatically if you do not respond for three rounds.

The shortcuts ⌘ ⇧ M and Ctrl + Shift + M work system-wide: they bring the window to the front and do the same thing as clicking the microphone, even when another app is in the foreground.

Chapter 12 / 17

What the assistant knows

Four things accompany every conversation. You can read, change, and disable each of them.

Instructions

Settings → Instructions. This is where you describe how the assistant should behave. Suspend instructions for this chat disables them for the open chat.

Memory

Settings → Memory. Rules and facts that apply across conversations. The assistant adds entries itself; you can read and edit them, or remove them all with Clear.

Send to local models — memory entries stay on this computer. Send to cloud models — memory entries are sent to the provider with every request.

Your name

You will find it under Preferred name on the Instructions page. The Greeting & preferred name switch displays the greeting and includes your name in requests to models. Turning it off disables both. With cloud models, your name is sent to the provider.

Skills

A skill is a written workflow. Invoke it by typing a slash followed by its name. The included skills are /cleanup, /cronjob, /grill-me, /handoff, /hilfe and /image-generator.

Settings → Skills: Suggest skills automatically lets the model select a skill without you naming one. Write a skill creates a custom skill. Reset restores a modified built-in skill to its original version.

The notes in exe.md in each approved folder are included as well (see Folders and documents).

Three limits on the Instructions page

Tool roundsHow many times the model may use a tool within one response. Tasks involving many files need more. Auto means 50.
Command timeoutMaximum runtime of a shell command, in seconds. Downloads and builds may need more time. Auto means 120.
Context compressionContext usage, as a percentage, at which a chat is summarized. The range is 1 to 85; Auto means 80.

Appearance

Choose from five themes — Pearl, Exe, Dark Matter, Heaven, and Moune — plus Custom gradient with your own colors and Auto, which follows your device's settings. A theme changes the entire window: frame, lines, messages, and code blocks.

Message color sets the color of your own messages. Under Code colors, choose from these color schemes: Exe, Tokyo Night, One Light, GitHub, GitHub Dark, Dracula, Nord, Solarized Light, and Solarized Dark. Layout mode adjusts the font size, chat width, and spacing between messages.

Updates

At startup, the app checks for a newer version. If one is available, the New version available card appears with Download, Install and Later.

Use Check for updates in Settings to check immediately.

Chapter 15 / 17

Your data

Exe AI is designed to keep your data with you.

  • The app is accessible only from your own computer (address 127.0.0.1). Chats, settings, keys, and models are stored locally in files and a database.
  • With a local model, nothing you type leaves your computer. With a cloud model, your text is sent to the provider.
  • API keys are stored in a local file with restricted permissions and are never displayed again. The interface only receives information about whether a key has been set.
  • Your memory entries are sent to cloud providers only if you enable that option. Your name accompanies every conversation, including those with cloud providers, as long as “Greeting & preferred name” is enabled.
  • Models are downloaded directly from huggingface.co.

Chapter 16 / 17

Terminal

Exe AI in a terminal: the command exe, the service without a window, and the commands inside a chat.

The command exe

After installation, exe works in every terminal and every folder. On macOS the app places a link at /usr/local/bin/exe on its first start; if that needs a password, the Mac asks for it once. On Windows the installer puts the command on your PATH; open a new terminal window after installing.

exe install places the link again at any time and names its path.

Starting

exe opens a new chat in the terminal. Where no service is running on this machine, exe starts one in the background and uses it; the service keeps running after you leave. exe --chat "Weekly report" opens the chat with that title. exe --version and exe --help need no service.
